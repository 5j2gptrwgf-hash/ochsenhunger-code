# Der Ochsenhunger-Code

Escape Room zur Definition der **Bulimia nervosa** – interaktives Klassenspiel für die Gruppenpräsentation „Wir werden Experten für eine Essstörung“ (Psychiatrie).

- 8 Schlösser (Wortherkunft, Kernmerkmale, Teufelskreis, Stimmt oder nicht?, Fallbeispiele, Codes & Kriterien, Fehler im Bericht, Lückentext) und ein Tresor-Code am Ende
- Die ganze Klasse spielt zusammen gegen die Uhr (Standard: 15 Minuten), Strafzeit bei falschen Antworten
- Läuft direkt im Browser, auch auf dem Handy – keine Installation nötig

**Spielen:** Seite über den Beamer öffnen, Vollbild mit `F` oder `F11`.

Quellen: Lieb (Hrsg.), *Intensivkurs Psychiatrie und Psychotherapie*, 10. Aufl. 2023; WHO ICD-10/ICD-11; DSM-5.
